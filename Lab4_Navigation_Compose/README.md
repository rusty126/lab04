# Navigation App — навигация в Jetpack Compose

## Автор
**Кара Артем Валерьевич**, группа **ПИН-б-о-24-1**.

## Описание
Учебное Android-приложение демонстрирует навигацию между списком пользователей, карточкой профиля и экраном редактирования.

## Технологии
- Kotlin
- Jetpack Compose и Material 3
- Navigation Compose
- Android Gradle Plugin 8.7.3
- Минимальная версия Android: API 24
- JDK 17

## Функциональность
- Список из шести пользователей в `LazyColumn`.
- Переход к профилю с передачей `userId` через `navArgument`.
- Отображение имени, возраста, города и электронной почты.
- Возврат через `popBackStack()`.
- Snackbar при открытии профиля.
- Экран редактирования с передачей изменённого имени обратно через `SavedStateHandle`.
- Сохранение состояния переменной фильтра списка с `rememberSaveable`.
- Логирование основных методов жизненного цикла Activity.

## Запуск
1. Распакуйте архив.
2. Откройте папку проекта в Android Studio.
3. Установите JDK 17 и Android SDK 35.
4. Дождитесь синхронизации Gradle.
5. Запустите приложение на эмуляторе или устройстве.

## Структура
- `data/` — модель и тестовые данные.
- `components/` — переиспользуемые карточки.
- `screens/` — экраны приложения.
- `navigation/` — граф навигации.
